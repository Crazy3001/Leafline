# Security

If you find a security problem in Leafline, please report it privately through [GitHub's private vulnerability reporting](https://github.com/Crazy3001/Leafline/security/advisories/new) rather than in a public issue.

Only the newest release gets fixes.

Download Leafline only from this repository's [releases page](https://github.com/Crazy3001/Leafline/releases). Copies from anywhere else may have been changed.
